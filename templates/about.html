About data and terms

OWASP
A not-for-profit foundation that publishes application-security guidance. This site uses a curated local teaching summary of the {{ owasp.edition }} edition; it does not scrape OWASP.
CVE
A public identifier for a reported vulnerability.
CWE
A classification of a weakness type, such as a category of coding mistake.
CVSS
A technical scoring system. It helps compare severity but does not measure the complete risk to your organisation.
NVD
NIST's database adds analysis to CVE records. Data fetched: {{ data.fetched_at or 'not available' }}.
CISA KEV
A catalogue of vulnerabilities known to be exploited. Missing from KEV does not prove a vulnerability is not exploited.

Sources and maintenance

NVD API 2.0 and CISA KEV JSON are retrieved dynamically when possible. OWASP data is local. When a new OWASP edition is released, a maintainer should read the official project, update data/owasp_top_10.json, record the source-check date, review each student explanation, test the page, and commit the change.
